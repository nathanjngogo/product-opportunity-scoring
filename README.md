# 产品机会评分

> 用统计方法给亚马逊产品看板打 1-5 星机会分。
> 从几百上千个产品里筛出值得做深度调研的候选池。

选品漏斗的第一道：**回答「先看哪些」，不回答「做不做」。**

---

## 它解决什么问题

拿到一份 Top100 或 Top500 看板，常见困境：

| 困境 | 本技能的做法 |
|---|---|
| 5000 个产品从哪看起 | 按机会分排序，Top 10% 优先 |
| 吸尘器月销 8000、手机壳月销 300，怎么比 | 类目内标准化，不跨类目比 |
| 类目 CR3=95%，还需要看吗 | 竞争度作为赛道分，烂赛道整体降权 |
| 容量小的类目是不是没机会 | 看趋势。容量不足时趋势加权补偿 |
| 权重怎么定 | 先跑 KMO 检验，数据不允许就不硬拍 |
| 为什么这个产品是 5 星 | 评分依据逐行输出，可在 Excel 里手工复核 |

## 四层模型

```
L1  类目内稳健标准化      每个产品只与同类目内产品比较
L2  产品竞争力分          七信号等权加权几何平均
L3  类目赛道分            容量 / 趋势 / 竞争度 / 新品
L4  两层乘法合成 + 硬约束  烂赛道好产品打五折
```

### L1 类目内稳健标准化

**为什么**：跨类目直接归一化会把「类目差异」混进「产品优劣」。

实测方差分解：

| 信号 | 组间方差占比 |
|---|---|
| 差评率 | 18.5% |
| Listing完整度 | 15.6% |
| 评价数 | 15.4% |
| 跟卖数 | 14.4% |
| 毛利额 | 11.8% |
| 月销量 | 9.9% |
| 评价增速 | 4.6% |

平均 13% 的方差来自类目差异。类目内标准化消除这部分（固定效应去均值）。

**实现**：
```
每个类目组内：
  Winsorize(P10, P90)  →  min-max → [0,1]
类目样本 <15 条时退到一级类目
类目内 <3 条时置 0.5（不提供组内信息）
```

**为什么 Winsorize**：原始数据偏度极大（评价增幅 31.22、跟卖数 -8.20），
任何基于均值方差的标准化都会被离群值主导。

**为什么不用秩变换**：秩变换会把分布压平为均匀分布，
导致熵值恒等、标准差恒等，后续所有「信息量」类赋权全部失效。

### L2 产品竞争力分（七信号）

| 信号 | 方向 | 含义 |
|---|---|---|
| 月销量 | 正 | 需求规模 |
| 评价增速 | 正 | 需求动量 |
| 评价数 | **反** | 进入壁垒 |
| 跟卖数 | **反** | 同质化 |
| 差评率 | 正 | 改良空间 |
| Listing完整度 | **反** | 对手运营水平 |
| 毛利额 | 正 | 单位赚钱能力 |

**聚合方式：加权几何平均**

```
score = exp( Σ(1/7) · ln(xᵢ + 0.02) )
```

**为什么几何平均不用算术平均**：

- 算术平均允许补偿：一个维度 0 分，其他 100 分，平均仍有 85.7
- 几何平均不允许：一个维度 0 分，总分归零

初筛是**淘汰赛不是计分赛**。任何一项接近 0 都应显著压低总分。

### L3 类目赛道分（四维度）

#### 市场容量 + 市场趋势

**容量**：类目月销额合计，`log10` 后取百分位。

**趋势**：`近6月均销量 / 前6月均销量 - 1`，Winsorize(P5,P95) 后取百分位。

**补偿逻辑**（关键设计）：

```python
# ❌ 错误写法（区间坍缩到 [90,100]，完全失去区分度）
ECAP = CAP + (100 - CAP) * TRD / 100

# ✅ 正确写法（加权几何）
theta = (100 - CAP) / 100 * 0.5
ECAP = CAP^(1-theta) * TRD^theta
```

| CAP | θ | 效果 |
|---|---|---|
| 100 | 0 | 纯看容量，趋势无影响 |
| 50 | 0.25 | 容量占 75%，趋势占 25% |
| 0 | 0.5 | 各占一半 |

θ 上限 0.5 的理由：容量为 0 意味着类目几乎没有市场，
趋势再好也只是「小市场在涨」，不该完全决定结果。

**先验证两维度是否独立**：`r(log容量, 趋势)` 实测 -0.174，
接近 0 说明补偿逻辑有意义（不是重复计量）。

#### 竞争度（CR 降维）

你可能会想直接看 CR3/CR5/CR10/CR20 四个指标。但先检验：

|  | CR3 | CR5 | CR10 | CR20 |
|---|---|---|---|---|
| CR3 | 1.000 | 0.975 | 0.845 | 0.675 |
| CR5 | | 1.000 | 0.935 | 0.788 |
| CR10 | | | 1.000 | 0.928 |
| CR20 | | | | 1.000 |

**PCA 的 PC1 解释 89.4%** —— 四档测的是同一个量，各算一维等于重复计量四遍。

**降维实现**：
```
主指标 = 100 - CR10 百分位
形态修正 = CR3/CR10 比值（越高越寡头）→ 扣 0~15 分
最终 = max(0, 主指标 - 形态惩罚)
```

#### 新品机会

**先检验两个指标是否冗余**：新品数量占比 × 新品销量占比，实测 **r = 0.935**。

合并为单一指标（各 50%）。新品判定：`上架天数 < 365`。

### L4 两层合成

```
CAT = (ECAP + CMP + NEW) / 3          # 类目赛道分
mult = 0.5 + 0.5 * CAT / 100
final = PROD * mult - penalty
```

**乘法 vs 加法的区别**：

| CAT | mult | 含义 |
|---|---|---|
| 0 | 0.5 | 烂赛道，好产品打五折 |
| 50 | 0.75 | 中等 |
| 100 | 1.0 | 好赛道，不打折也不放大 |

加法会让「烂赛道+好产品」和「好赛道+一般产品」同分，不符合实际。
乘法保证**类目只减分不加分**。

**硬约束**（只有 1 条，实测命中率 3%）：

| 条件 | 扣分 |
|---|---|
| 评价 > 20,000 且评分 ≥ 4.5 | -20 |

成熟红海，新品无法挤入。其他候选约束在信号层已体现，重复惩罚会导致双重扣分。

## 权重决策流程（最重要的一节）

**不要跳过这一步直接给权重。**

```
Step 1  算相关矩阵（Spearman，抗离群）
        → 找 |ρ|>0.5 的冗余对

Step 2  算 KMO
        <0.6  → 数据不支持因子分析，用等权
        0.6-0.8 → 可考虑 PCA 载荷，但需与等权对比
        >0.8  → 可做因子分析

Step 3  平行分析 → 确定真实独立维度数

Step 4  方差分解 → 决定是否类目内标准化

Step 5  按结果选权重方案，把理由写进报告
```

**实测结果（真实数据，2143 条）**：

```
KMO = 0.4842
特征值: [1.945, 1.297, 1.084, 1.012, 0.791, 0.616, 0.254]
PC1 解释 27.8%
最大特征值 < 1（无主导因子）
→ 结论：等权
```

**依据**：OECD/JRC《Constructing Composite Indicators》手册——
维度间相关性很低时，主观或数据驱动赋权都缺乏依据，等权可避免过拟合样本噪声。

这一步能省掉至少 5 轮无效迭代。我们在 `references/pitfalls.md` 里记录了
7 个失败的权重方案及各自的失效原因。

## 真实数据表现

2143 个产品，四维初筛后：

| 星级 | 数量 | 占比 | 评价中位 | 评分 | 差评率 |
|---|---|---|---|---|---|
| 5 星 | 215 | 10% | **141** | **4.47** | **23.7%** |
| 4 星 | 428 | 20% | 368 | 4.49 | 16.1% |
| 3 星 | 643 | 30% | 1,038 | 4.53 | 12.5% |
| 2 星 | 535 | 25% | 2,600 | 4.59 | 9.7% |
| 1 星 | 322 | 15% | **6,024** | **4.66** | **7.4%** |

**5 星特征**：卖得比同行好（月销 3,400+）、赚得比同行多（毛利额 $34）、
但评价积累还很少（141 条）、差评还比较多（23.7%）。

这正是可切入的窗口：**需求已验证、壁垒未形成、痛点明确**。

## 已知局限

1. **没有真值验证**。所有检验都是内部一致性。真正检验需要「哪些产品后来成功了」的外部门样本。

2. **CR 是样本内 CR**。基于本表产品计算，不是真实类目大盘。样本少的类目 CR 天然偏高。缓解：类目 n≥15 才用二级分类。

3. **趋势是样本内趋势**。如果新品大量涌入，即使大盘在涨，老产品销量也可能跌。

4. **几何平均对新品略不利**。新品评价数少 → 评价数维度在类目内偏低 → 压分。专找新品时应调低该信号权重。

5. **类目分层混用**。部分用二级、部分用一级，两者 CR 不可直接比较。

## 兼容性

- **输入**：Sorftime / 卖家精灵等导出的产品看板 Excel
- **字段要求**：类目路径、月销量、月销额、评价数、评分、差评率、毛利额、跟卖数、Listing完整度、上架天数
- **可选增强**：销量趋势表（有则启用市场趋势维度）
- **表格格式**：兼容 `inlineStr`（原始导出）与 `sharedStrings`（openpyxl 处理过）
- **列定位**：按表头名称匹配，不依赖列字母位置（可处理插入过列的表）
